# กระดานไร้ขอบ

กระดานวาดรูปพื้นที่ไม่จำกัด ทุกคนเข้ามาวาดพร้อมกันและเห็นเส้นของกันและกันแบบเรียลไทม์
มีรูปแบบ (import รูป ปรับความโปร่งใส ปรับขนาด ล็อกไว้แล้ววาดทับ) ที่เห็นเฉพาะตัวเอง

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html`, `style.css`, `script.js` | ตัวเว็บ |
| `config.js` | ที่ใส่ค่า Supabase ของคุณ |
| `supabase.sql` | สร้างตารางเก็บงาน |

## ตั้งค่า (ทำครั้งเดียว ประมาณ 5 นาที)

1. สมัครที่ supabase.com แล้วสร้างโปรเจกต์ใหม่ (แผนฟรีใช้ได้)
2. เมนู **SQL Editor** → New query → วางเนื้อหาจาก `supabase.sql` → กด Run
3. เมนู **Project Settings → API** คัดลอก **Project URL** และคีย์ **anon public** ไปใส่ใน `config.js`
4. อัปโหลดไฟล์ทั้งหมดขึ้น repo ของคุณ (GitHub → Add file → Upload files) แล้วรอ GitHub Pages อัปเดต

ถ้าจะวางไว้โฟลเดอร์ย่อย (เช่น `draw/`) เพื่อไม่ให้ทับไฟล์เดิมของเว็บ ก็ย้ายทั้งชุดเข้าไปได้เลย
ไฟล์ `CNAME` เดิมไม่ต้องแตะ

ถ้าเชื่อมต่อไม่ติด ให้เปิด **Realtime → Settings** ใน Supabase แล้วเช็กว่าเปิด "Allow public access" ไว้

## วิธีใช้

- แชร์ลิงก์ให้เพื่อน ใครเปิดลิงก์เดียวกันจะอยู่ห้องเดียวกัน
- ห้องแยกกันด้วย `?board=ชื่อห้อง` ท้ายลิงก์ หรือกดปุ่มมุมขวาบน (จุดสีเขียว + จำนวนคน) เพื่อตั้งชื่อ เลือกสี และสลับห้อง
- ปุ่มรูปภาพบนแถบเครื่องมือ (หรือกด `I`) เพิ่มรูปแบบได้ ลากไฟล์มาวางหรือกด Ctrl + V ก็ได้
- ปุ่มชั้นซ้อนมุมล่างขวาเปิดแผง “รูปแบบ” สำหรับปรับความโปร่งใส ขนาด ล็อก ซ่อน และเลือกให้ทับหรืออยู่ใต้เส้น

## ควรรู้

- **ความปลอดภัย** นโยบายใน `supabase.sql` เปิดให้ทุกคนวาดและลบได้ เหมาะกับกระดานสาธารณะหรือกลุ่มเพื่อน
  ถ้ากลัวคนมาป่วน ให้ตั้งชื่อห้องที่เดายาก และถ้าต้องการจำกัดสิทธิ์จริงจังให้เพิ่มระบบล็อกอิน (Supabase Auth) แล้วแก้นโยบาย
- คีย์ anon public ใส่ในเว็บได้ตามปกติ ห้ามเอาคีย์ `service_role` มาใส่
- รูปแบบเก็บในเบราว์เซอร์ของแต่ละคน (IndexedDB) ไม่ถูกอัปโหลด ล้างข้อมูลเว็บแล้วรูปจะหาย
- ปุ่ม “ลบเส้นทั้งหมดที่ฉันวาด” ในหน้าต่างห้องจะลบเฉพาะของเบราว์เซอร์นั้น
- ถ้ายังไม่ได้ใส่ค่าใน `config.js` เว็บจะทำงานในโหมดวาดคนเดียว และเก็บงานไว้ในเครื่อง
